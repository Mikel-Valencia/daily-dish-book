# Technology Stack

The purpose of this file is to define and describe the technology stack used for the development of this project.

## Core Technologies

- [PNPM](https://pnpm.io/). A fast, disk space efficient package manager used in Node.js environment.
- [Astro](https://astro.build/). A web framework for content-driven websites.
- [HTML](https://developer.mozilla.org/es/docs/Web/HTML). The basic component of a website or web application. Defines the structure and content of a web.
- [CSS](https://developer.mozilla.org/es/docs/Web/CSS). A stylesheet language that allows to apply styles into HTML or XML documents, or documents based on these.
- [PostCSS](https://postcss.org/). A tool for transforming styles using JavaScript plugins.
- [TypeScript](https://www.typescriptlang.org/). A strongly typed language built on JavaScript.
- [MDX](https://mdxjs.com/). Combines markdown and JSX languages, allowing to use JSX in a markdown content.
- [Zod](https://zod.dev/). A TypeScript-first validation library. It is used to define schemas for data validation.

## Development Tools

### Code Editor

- [VS Code](https://code.visualstudio.com/). A lightweight and extensible code editor for software applications.

#### VS Code Extensions

- [Astro VS Code Extension](https://marketplace.visualstudio.com/items?itemName=astro-build.astro-vscode). VS Code support for Astro projects.
- [ESLint VS Code Extension](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint). VS Code support for ESLint.
- [MDX VS Code Extension](https://marketplace.visualstudio.com/items?itemName=unifiedjs.vscode-mdx). VS Code support for MDX.
- [Prettier VS Code Extension](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode). VS Code support for Prettier.
- [Stylelint VS Code Extension](https://marketplace.visualstudio.com/items?itemName=stylelint.vscode-stylelint). VS Code support for Stylelint.

### Linters

- [Stylelint](https://stylelint.io/). A CSS linter that helps avoiding errors and enforcing conventions.
- [ESLint](https://eslint.org/). A static code analysis tool to find and fix problems with JavaScript code.

### Code Formatters

- [Prettier](https://prettier.io/). An opinionated code formatter that ensures outputted code conforms to a consistent style.

## Project Versioning and Hosting

### Version Control Tools

- [Git](https://git-scm.com/). A distributed version control system that allows to register and track working changes in a software project.

### Project Hosting Services

- [Github](https://github.com/). A cloud hosting service for a project's source code.
- [Github Pages](https://docs.github.com/en/pages). A static site hosting service that takes HTML, CSS, and JavaScript files straight from a repository on GitHub, optionally runs the files through a build process, and publishes a website.
